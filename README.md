### Запуск в Termux (Android)

Скрипт автоматически определяет запуск в **Termux** (или отсутствие графического экрана) и переключается в удобный **консольный режим (CLI)** без необходимости настраивать X11/VNC. Видео по умолчанию сохраняются сразу в папку **«Загрузки»** телефона (`~/storage/downloads`).

#### Быстрая установка в Termux (одной командой)

```bash
pkg update -y && pkg install -y git
git clone https://github.com/doromere/Vk.git
cd Vk
bash setup_termux.sh
```

Что делает `setup_termux.sh`:
1. Устанавливает `python` и `ffmpeg` (для склейки видео и аудио в максимальном качестве).
2. Запрашивает доступ к памяти телефона (`termux-setup-storage` — нажмите **«Разрешить»**).
3. Устанавливает зависимости из `requirements.txt` (`yt-dlp`, `requests`).
4. Добавляет быструю команду `vkdl` и настраивает меню **«Поделиться -> Termux»** (`~/bin/termux-url-opener`).

#### Как пользоваться в Termux после установки

- **Через меню «Поделиться» на Android:** откройте видео в приложении VK, браузере, Rutube или YouTube, нажмите **«Поделиться» -> «Termux»** — скачивание начнётся автоматически.
- **Интерактивное меню в консоли:**
  ```bash
  vkdl
  # или: python vk_video_download.py
  ```
- **Прямое скачивание по ссылке (одной или нескольким):**
  ```bash
  vkdl "https://vk.com/video-87011294_456249654"
  ```

#### Параметры командной строки

```bash
python vk_video_download.py [ССЫЛКИ...] [--cli | --gui] [-o ПАПКА] [-r] [-l] [-f] [-w ПОТОКИ]
```
- `--cli` — принудительно запустить консольный режим
- `--gui` — принудительно запустить графическое окно (`tkinter`)
- `-o, --output-dir ПАПКА` — папка сохранения видео
- `-r, --random-name` — случайное имя файла
- `-l, --limit-length` — ограничить длину названия до 50 символов
- `-f, --folder` — отдельная подпапка для каждого видео
- `-w, --workers N` — число параллельных загрузок (по умолчанию `3`)

#### Что это?

Скрипт на Python 3 с графическим (Tkinter) и консольным (CLI / Termux) интерфейсом для скачивания видео с сервиса vk.com и других площадок.

#### Как начать использовать на ПК (Windows / Linux / macOS)?

1. Скачайте архив с последней версией (или клонируйте репозиторий);
2. Установите зависимости:
   ```bash
   pip install -U -r requirements.txt
   ```
3. Запустите скрипт:
   ```bash
   python vk_video_download.py
   ```
4. В появившемся окне вставьте ссылку на видео в поле ввода и нажмите кнопку *Скачать видео*;
5. Видео будет сохранено в папке `downloads`.

> Ссылка должна быть вида: *https://vk.com/video-100000000_100000000*

#### Возможные проблемы

- Видео не скачивается
> Видео или закрыто для доступа посторонним, или имеет формат/источник, не поддерживаемый yt-dlp. Попробуйте обновить `yt-dlp`: `pip install -U yt-dlp`.

- У файлов после скачивания формат `.unknown_video` или нет звука
> Убедитесь, что установлен `ffmpeg`, либо переименуйте файл в `.mp4`.

- Куда скачивается готовое видео?
> На ПК — в директорию `downloads` рядом со скриптом `vk_video_download.py`. В Termux — в `~/storage/downloads` (папка «Загрузки» телефона).

#### Состав репозитория

* **vk_video_download.py** — основной скрипт (GUI + CLI)
* **setup_termux.sh** — автоустановка для Android Termux
* **theme/** — папка с темой оформления для графического окна
* **requirements.txt** — зависимости (`yt-dlp`, `requests`)

Команда на сборку exe файла в pyinstaller:

    pyinstaller vk_video_download.py --noconsole --onefile --icon=theme/icon.ico
